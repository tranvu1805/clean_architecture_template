# 0.1.0+1

## Initial Release

### Features
- ✨ Clean Architecture foundation with core layer structure
- 🔥 Error handling with functional programming (fpdart)
- 🌐 Pre-configured HTTP API service with error handling
- 🧭 Go Router setup with shell navigation
- 🎨 Material 3 theme system with custom color palette
- 🔧 GetIt dependency injection setup
- 📦 Automatic dependency installation via post-generation hook
- 🚀 Pre-generation hook for project name extraction

### Core Components
- Type definitions for functional error handling
- Base UseCase interfaces
- Exception and Failure classes with factory methods
- Network timeout handling
- Route constants and navigation shell
- Utility methods for API responses
- Common local data source interface

### Dependencies
- flutter_bloc, equatable, http, get_it, go_router, fpdart
- flutter_launcher_icons, bloc_test, mocktail
